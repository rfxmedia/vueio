Sharing and delivery

Let collaborators review and receive media through a browser while the underlying files stay on storage you control.

Before you send a link

Remote recipients need a reachable HTTPS address for your Vue.io host. A localhost address, a sleeping laptop, or a disconnected drive cannot serve a remote review. Your host's upload bandwidth affects playback and downloads.

Configure remote access →

Share a review

  1. Open the media, tracker, or supported folder you want to share.
  2. Use its share action and review the access options for that target.
  3. Confirm which content and downloads the recipient should receive.
  4. Copy the generated link and open it in a signed-out browser window.
  5. Check the content and available actions before sending it.

Share options vary by target. Where available, set a password or expiration and choose whether downloads are allowed. A link does not automatically give someone access to the whole project or administrator controls. Use project membership for ongoing team work and scoped links for specific handoffs.

Deliver files

Confirm the selected shot versions and delivery contents before using a download or Download All action. For a large delivery, verify a small download through the same link and network first.

Original media, previews, and attachments are distinct files. A browser preview does not establish that every expected source file is included in a delivery. Check the filenames and contents of the resulting download.

Request incoming files

Use a folder's file-request sharing options when someone needs to upload into a selected location. Check that uploads are enabled and the request points to the intended folder. Try a small test file and confirm it arrives before handing off a large transfer.

File requests are subject to capacity, configured limits, and proxy or tunnel limits. They are not unlimited public storage.

Upload limits and request behavior →

Change or end access

Review a link's settings when the handoff is complete. Disabling a share stops future access through it; it cannot recall files someone already downloaded. Do not post private share links in public support requests.
