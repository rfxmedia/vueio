# Security policy

Vue.io is currently a public alpha. Supported security fixes target the newest
published alpha release.

Please report suspected vulnerabilities privately through the repository's
GitHub **Security** tab using **Report a vulnerability**. Do not open a public
issue containing credentials, private share links, storage paths, or exploit
details.

When reporting a problem, include the Vue.io release tag, deployment model,
affected route or feature, reproduction steps, and whether the instance was
reachable from the public internet.
